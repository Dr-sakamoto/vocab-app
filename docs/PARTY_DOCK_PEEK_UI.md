# 手持ち欄（スマホ・のぞき見ドック）UI 仕様メモ

> このメモは、スマホ版の最下段に常設していた「手持ち欄（のぞき見ドック）」を
> **一旦削除**するにあたり、後で復元できるよう UI 形式を記録したもの。
> 削除後は、ボックス管理画面の上部（`エティモン管理` ヘッダ）がそのまま最下段の
> のぞき見になり、引き上げると地続きにボックス管理画面へ広がる方式に変更した。
>
> コンポーネント本体 `app/components/EtymonDock.tsx` は **PC版で継続使用中** の
> ため残してある（`asPeek` プロップがスマホののぞき見モードだった）。スマホの
> のぞき見として復活させたいときは、この仕様と `EtymonDock`（`asPeek` 分岐）、
> および削除前の `EtymonPartySheet`（git 履歴 #116 系）を参照する。

## 見た目・構成（削除したスマホののぞき見ドック）

- 位置: スマホ版スクリーン最下段の `footer`（高さ約 `h-32` = 128px）に常設。
- 台座: `wood-panel` の横並び。バトル参加中の手持ち **4体** の札を等幅で並べる
  （`getPartySlots(...).slice(0, BATTLE_PARTY_SIZE)`, `BATTLE_PARTY_SIZE = 4`）。
- 各札:
  - スプライト画像（`imageRendering: pixelated`, 高さ最大70%）
  - 名前（`text-[10px]〜xs`, `truncate`）
  - `Lv.<level>`（`font-fantasy`, 小さめ）
  - アクティブ（`activeId` 一致）は `parchment` + 発光シャドウ、非アクティブは
    黒地＋薄枠。
  - 空きスロットは破線枠に `+`。
- 右端: 真鍮プレート（`brass-btn`）の **ATK** 表示。
  `getPartyAttackPower(...)` の値（1正解あたりの与ダメージ）。
- 取っ手: 台座上辺中央に彫り込んだ「凹」の持ち手（`rounded-b-full`＋内側の
  白いつまみ）。タップ or 上方向ドラッグで編成ドロワー（控えボックス）が開く。

## 操作（削除した挙動）

- 札タップ = その手持ちを **せんとう（アクティブ）** に切替（`onSelect(monsterId)`
  → `setActiveMonster`）。※スマホでアクティブを切り替える主要動線だった。
- 取っ手タップ / 上ドラッグ = 控えボックス（`PokemonBox`）が下から地続きに
  せり上がる（`EtymonPartySheet` の progress 追従）。

## 復元時の注意

- スマホでアクティブ手持ちを切り替える動線が、このドック削除で失われている。
  復活させない場合は、ボックス管理画面（`PokemonBox` の「手持ち」セクション）
  側にアクティブ切替の導線を持たせるか検討する。
- PC版は `DesktopGameScreen` で `EtymonDock`（`asPeek` なし = 自前の取っ手つき）
  を今も使用しているため、`EtymonDock.tsx` は削除しない。
